# Ritmo

Rastreador de hábitos no navegador.

- Marcação diária na semana e no mês
- Calendário de sequências por hábito
- Estatísticas: sequência atual, recorde, conclusão em 30 dias e dias perfeitos
- Adicionar, editar, excluir e escolher cor
- Dados apenas no `localStorage` deste navegador (`ritmo.v1`)

Abra `index.html`.
